# FR-05.05 / FR-05.08 / FR-04.06 — Module Directory & Dialog Status Consolidation, 18 November 2026

## Scope and results

- **Unified 7-column `Module Directory` (`AC-01`, `AC-02`)**: Replaced the three separate `Lifecycle`, `Review`, and `Workflow` columns in `ModuleManagementWorkspace.tsx` with a single `Status` (`Trạng thái`) column across both the desktop/tablet directory table (`Module`, `Responsible person`, `Skill taught`, `Knowledge level`, `Duration`, `Status`, `Action`) and mobile cards. Each row renders one primary status `<Badge />` (`Released`, `Published revision N`, `Submitted`, `Returned for changes`, `Draft`, `Archived`, or catalog status fallback) and displays a secondary muted note underneath only when a released module has an active working revision, lacks authoring records, or needs lesson content.
- **Unified `Status` filter dropdown (`AC-03`)**: Consolidated the separate `Lifecycle` and `Review` filter selects into one `Status` (`Trạng thái`) dropdown (`All`, `Released`, `Active`, `Pending review`, `Changes requested`, `Draft`, `Archived`) mapped to the existing backend `status` and `review` query parameters.
- **Consolidated Dialog Header status badge (`AC-04`)**: Simplified the header badges in `CatalogModuleDetails.tsx` and the working-revision detail dialog in `ModuleManagementWorkspace.tsx` to display a single `Status` badge while retaining low-level relationship fields inside the collapsible `Technical metadata` section.
