# FR-06.07 / FR-06.08 — Skill-level assessment presentation, 17 November 2026

## Scope and results

The new Skill Assessment section belongs to the selected Skill/knowledge-level tab and appears above module cards. Cards retain learning/review controls. When several completed modules match the current Skill version and level, the learner explicitly chooses one as completion evidence. The selected module/revision retains its own assessment history and retake limits; this UI does not consolidate them across modules. The Reader entry remains available. Global module search offers View skill to open the owning Skill and exact module knowledge level, retaining search state on Back.

## Manual check

1. Sign in as Employee on http://localhost:8088; open Upskilling → Skills → View modules.
2. Choose Foundation, Intermediate or Advanced. Skill Assessment appears above the modules; unfinished/invalid/current-version mismatch leaves an explanatory message.
3. With one completed eligible module, check Learning evidence; with several, choose a completed module first. Assessment history/retake limits refer to that selection. Viewing/changing selections must not create an exam.
4. Explicitly open/resume/retake using the existing assessment action. Existing server policy and question-bank checks apply; learning progress remains on denial.
5. Module cards only start/continue/review learning. On global Modules results, View skill opens the owning Skill at the module level; Back restores search and focuses the originating View skill link.
6. At390px check wrapping and keyboard labels. In Reader, the assessment entry and history behavior remain available.

Not a fullCI/production claim. No migration, new assessment bank or achievement recalculation. A real exam start/retake was intentionally not performed in shared local acceptance.
