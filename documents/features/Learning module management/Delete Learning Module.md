# Delete Learning Module

**Function ID:** REQ-013-F04  
**Actor:** Domain Expert  
**Status:** Pending clarification  
**Feature:** [Learning Module Management](README.md)

## Description

Remove an authorized module from use while respecting existing pathways, outcomes, and assessment references.

**Input:** Module and removal request.  
**Outcome:** Deleted/archived module or a blocked request under the agreed policy.

## Open Decisions

- Deletion versus archival and active-pathway dependency checks.
- Replacement behavior and treatment of unfinished assessments.
- Restore support and whether historical descriptions remain visible.

## Acceptance Baseline

Removal must not silently corrupt an employee's existing pathway or assessment history.
