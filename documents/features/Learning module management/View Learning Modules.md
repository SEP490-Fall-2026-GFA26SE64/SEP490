# View Learning Modules

## Current Scope Alignment
Expert views assigned-discipline modules and their configuration/submission status for authoring. Employee approved-content access is separately REQ-007/055. Follow the [current feature contract](README.md#current-scope-alignment) and [System Overview](../../adapt_learn_graph_system_overview.md).

**Module–Skill mapping (v0.9.0):** A Module may teach several skills and a skill may have several teaching Modules. Return all current mapped skill IDs for authoring/viewing. Published mappings require actual teaching content; completion does not automatically pass all skills.

## Historical Specification
Conflicting actors, policies and acceptance below are superseded; old evidence is not revised-scope certification.

**Function ID:** REQ-013-F02  
**Actor:** Domain Expert  
**Status:** Pending clarification  
**Feature:** [Learning Module Management](README.md)

## Description

Browse and inspect authorized dummy learning modules for maintenance and mapping.

**Input:** Expert scope and optional module filters.  
**Outcome:** Module catalog and detail view within authorized scope.

## Open Decisions

- Search/filter fields, list columns, and pagination.
- Visibility of draft/archived modules and assessment previews.
- Whether usage in active pathways is shown to experts.

## Acceptance Baseline

Expert catalog access does not imply employee access to modules outside system-selected pathways.
