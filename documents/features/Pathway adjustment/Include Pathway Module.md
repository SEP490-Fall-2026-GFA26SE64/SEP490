# Include Pathway Module

**Function ID:** REQ-020-F01  
**Actor:** Domain Expert  
**Status:** Pending clarification  
**Feature:** [Pathway Adjustment](README.md)

## Description

Include a permitted module in the employee pathway under expert review. Employees do not receive this selection capability.

**Input:** Reviewed pathway, module, and any required expert justification.  
**Outcome:** An expert-adjusted pathway containing the module.

## Open Decisions

- Eligible module catalog and required justification.
- Placement by the system versus expert placement; duplicate and prerequisite validation.
- Publication/notification and whether later automatic recalculation preserves the inclusion.

## Acceptance Baseline

Only an authorized expert can include a module, and the adjustment is distinguishable from algorithm-selected recommendations.
