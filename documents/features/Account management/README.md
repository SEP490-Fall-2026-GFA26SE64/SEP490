**Source:** [System Overview](../../adapt_learn_graph_system_overview.md); REQ-022. **Actor:** System Administrator. **Status:** Reclarification required.

Organization Administrator/Platform Administrator privileges are superseded. The legacy Delete function must be revised for lifecycle/reference retention rather than presumed physical deletion.
