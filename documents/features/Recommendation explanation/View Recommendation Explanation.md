## Current Scope Alignment
Employee views gap/prerequisite explanations for system recommendations; Expert reviews those explanations before initial pathway confirmation. Follow the [current feature contract](README.md#current-scope-alignment) and [System Overview](../../adapt_learn_graph_system_overview.md).

**Status:** Pending clarification  
**Feature:** [Recommendation Explanation](README.md)

## Description

Explain why a particular module belongs in the employee's pathway using its intended outcomes, a target-role gap, or a prerequisite dependency.

**Input:** Recommended module, pathway context, and supporting skill evidence.  
**Outcome:** A module-specific explanation grounded in the recommendation's actual evidence.

## Open Decisions

- Text, highlighted graph relationships, numeric gap scores, or a combination.
- Whether to display question-level evidence and expert inclusion reasons.
- How to explain missing evidence or an outdated recommendation.

## Acceptance Baseline

Each available explanation identifies a relevant gap or prerequisite rather than presenting a generic unsupported recommendation claim.
