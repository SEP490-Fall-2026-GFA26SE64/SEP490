# Learning Offering Approval

**Requirement:** REQ-053  
**Actors:** Expert submits; L&D Manager reviews and decides  
**Status:** Scope draft; approval/version policy pending  
**Source:** [System Overview](../../adapt_learn_graph_system_overview.md)

| Function ID | Function | Input | Outcome |
| --- | --- | --- | --- |
| REQ-053-F01 | Submit Learning Offering for Approval | Authorized Expert's new/revised module or assessment | Submission available to L&D |
| REQ-053-F02 | Review Submitted Learning Offering | Authorized L&D and submitted offering | Content/evidence visible for decision |
| REQ-053-F03 | Approve Learning Offering | Submission and authorized L&D approval | Offering approved for organizational use |
| REQ-053-F04 | Return Learning Offering for Revision | Submission and L&D revision feedback | Expert can revise returned offering |

**Acceptance:** Each of modules and assessments can be submitted, reviewed, approved, or returned. Employee use cannot treat a merely authored/submitted item as approved. Expert authorship does not grant L&D approval authority.
**Open decisions:** Completeness checks, feedback requirements, item versus aggregate approval, revision versioning, effect on active learning/attempts, and notifications.
**Entities/design gaps:** Submission/review history and approved content versions; no database status enum is selected here.
