# Reassign Target Role Expert

**Function ID:** REQ-024-F02  
**Actor:** Organization Administrator  
**Status:** Pending clarification  
**Feature:** [Expert Assignment](README.md)

## Description

Change the expert responsible for an organization target role and update the corresponding management access.

**Input:** Existing assignment and replacement expert.  
**Outcome:** Updated role responsibility and access rights.

## Open Decisions

- Immediate transfer versus an effective date or handover period.
- Treatment of pending reviews, unpublished graph changes, and active editing sessions.
- Historical attribution and notification to affected experts.

## Acceptance Baseline

Responsibility changes preserve prior review attribution while enforcing the newly agreed access scope.
