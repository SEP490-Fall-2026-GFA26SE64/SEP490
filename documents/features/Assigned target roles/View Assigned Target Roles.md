# View Assigned Target Roles

**Function ID:** REQ-011-F01  
**Actor:** Domain Expert  
**Status:** Pending clarification  
**Feature:** [Assigned Target Roles](README.md)

## Description

List roles assigned by the Organization Administrator and open the corresponding authorized role-management workspace.

**Input:** Expert identity and active role assignments.  
**Outcome:** A list of authorized target-role workspaces.

## Open Decisions

- List fields, filters, and whether review workload is shown.
- Multiple experts per role and ownership versus contributor permissions.
- Visibility of previous assignments and handling reassignment during an edit.

## Acceptance Baseline

An expert cannot use this workspace to manage a role outside their authorized assignments.
