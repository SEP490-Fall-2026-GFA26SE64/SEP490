# Link Micro-Skill to Target Role

**Function ID:** REQ-015-F01  
**Actor:** Domain Expert  
**Status:** Pending clarification  
**Feature:** [Role Requirements](README.md)

## Description

Connect a micro-skill to an assigned target role so gap analysis treats it as a role requirement.

**Input:** Assigned target role, permitted micro-skill, and requirement attributes.  
**Outcome:** A role-to-skill requirement relationship.

## Open Decisions

- Required versus optional skills, weights, and default proficiency.
- Duplicate links, bulk selection, and allowed shared-catalog skills.
- Publication and the effect on employees already pursuing the role.

## Acceptance Baseline

Only experts authorized for the target role can add its skill requirements.
