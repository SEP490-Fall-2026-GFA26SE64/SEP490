# Delete Target Role

**Function ID:** REQ-023-F04  
**Actor:** Organization Administrator  
**Status:** Pending clarification  
**Feature:** [Target Role Management](README.md)

## Description

Remove an organization target role while protecting employee selections, pathways, assessments, and expert assignments that reference it.

**Input:** Target role and deletion request.  
**Outcome:** Deletion/archival or a blocked request under the selected policy.

## Open Decisions

- Conditions for archival versus hard deletion.
- Active-employee migration, expert assignment removal, and prerequisite reference handling.
- Historical visibility and restoration.

## Acceptance Baseline

Deleting one target role does not delete shared skill definitions or silently invalidate recorded employee evidence.
