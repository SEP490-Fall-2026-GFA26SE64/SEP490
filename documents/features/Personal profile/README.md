# Personal Profile

**Requirement:** REQ-056  
**Actor:** Employee  
**Status:** Scope draft; editable field inventory pending  
**Source:** [System Overview](../../adapt_learn_graph_system_overview.md)

| Function ID | Function | Input | Outcome |
| --- | --- | --- | --- |
| REQ-056-F01 | View Personal Profile | Authenticated Employee | Own personal/work profile information |
| REQ-056-F02 | Update Personal Profile | Employee and permitted profile changes | Validated own profile updates |

**Acceptance:** Employee can view/update their permitted profile information. Profile editing cannot change access roles, another Employee's profile, recorded answers, or computed competency estimates.
**Open decisions:** Required/editable fields, work-information ownership, validation, identity reconciliation, privacy/retention, and effects on guidance.
**Entities/design gaps:** Employee profile field inventory and account relationship must be agreed before implementation; no new personal data field is inferred.
