# View Subscription Offerings

## Current Scope Alignment
Retired SaaS scope; follow the [disposition](README.md#current-scope-alignment). No current subscription selection workflow is required.

## Historical Specification
The material below is not a current implementation requirement.

**Function ID:** REQ-028-F01  
**Actor:** Organization Administrator  
**Status:** Pending clarification  
**Feature:** [Subscription Payment](README.md)

## Description

Display available platform subscription offerings for organization purchase.

**Input:** Organization context and available subscription configuration.  
**Outcome:** A list of available offerings and their applicable commercial terms.

## Open Decisions

- Plan structure, currency, tax presentation, billing periods, and entitlements.
- Current plan comparison, upgrade/downgrade eligibility, and trials.
- Whether retired or unavailable plans remain visible to existing subscribers.

## Acceptance Baseline

The displayed purchasable offering corresponds to the subscription configuration used to calculate payment.
