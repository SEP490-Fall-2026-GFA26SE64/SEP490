# Compare Benchmark Results

**Function ID:** REQ-036-F01  
**Actor:** Platform Administrator  
**Status:** Pending clarification  
**Feature:** [Benchmark Comparison](README.md)

## Description

Compare algorithms or completed runs for the same research question using compatible data and clearly identified metrics. RQ1 uses Content-Based Filtering as the registration baseline.

**Input:** Selected runs/algorithms and comparison criteria.  
**Outcome:** Comparable metrics and explicit differences in experiment configuration.

## Open Decisions

- Maximum compared runs and compatibility checks for datasets, hardware, and parameters.
- Absolute/percentage differences, charts, significance testing, and export.
- Blocking incompatible comparisons versus warning and labeling them.

## Acceptance Baseline

The comparison does not silently treat different datasets or incompatible metric definitions as a controlled experiment.
