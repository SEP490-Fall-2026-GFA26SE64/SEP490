# Research templates

These are empty field guides, not generated datasets, approvals or results.

- [Run manifest](run-manifest.example.json): copy into the new run directory and populate actual provenance. `TEMPLATE` is not an executable/accepted run status.
- [Annotation record](annotation-record.example.json): one real reviewer/profile/module judgment; null fields remain uncollected until real assessment.
- [RQ1_Expert_Gold50_Top5_Form.html](RQ1_Expert_Gold50_Top5_Form.html): offline form that reviewers use to rate modules and choose up to five priorities for each of the 50 gold profiles. The consensus shortlist [RQ1_Golden_Set_50_Dong_Thuan.xlsx](../RQ1_Golden_Set_50_Dong_Thuan.xlsx) uses this kind of priority selection. Keep it as the instrument behind that reference.
- [RQ1_Expert_Pilot_Form.html](RQ1_Expert_Pilot_Form.html): the same form for the pilot10 development profiles.

Never fill reviewer/time/result fields with fictional values. See [data contracts](../DATA_AND_REPRODUCIBILITY.md) and [expert guide](../EXPERT_ANNOTATION_GUIDE.md).
