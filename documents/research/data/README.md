# Research datasets

- [Application Developer catalog v0.1](rq1/application-developer-v0.1/README.md): 20 skills, 72 module specifications; expert review pending.
- [RQ1 profiles v0.1](rq1/profiles-v0.1/README.md): 500 draft synthetic profiles, 450 development and 50 held-out gold inputs; pilot10 is a subset of development. The catalog snapshot is pinned inside this dataset.

No human relevance labels or final experiment results exist. Golden inputs are not verified gold answers. User authorization permits preparing profiles on the draft catalog; catalog review, profile review and freeze remain required before final evaluation. Preserve versions and independent reviewer records. Follow [data contracts](../DATA_AND_REPRODUCIBILITY.md).
