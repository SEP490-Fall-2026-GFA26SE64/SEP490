# Keeping test evidence reproducible

Content version 1.0. Local authored introduction awaiting expert review.

## Explanation

Record the environment and the input needed to repeat a result. Separate the expected result, actual result and interpretation of impact. Confirmation testing checks a repair; regression testing checks that other required behaviour still works. A defect priority is a proposed scheduling decision, not a substitute for its observed severity.

## Worked example

A saved record disappears after refresh. Record the steps, environment and the value entered. Show what was expected after refresh and capture the observed absence. After repair, repeat that scenario and check another existing record remains intact.

This is an illustrative teaching scenario, not a measured learner result.

## Check your understanding

What makes a defect report useful to someone who did not run the test?

Answer: It preserves enough conditions and evidence to reproduce and interpret the failure.
