## Skill focus

- **MS-DE02: develop data processing applications** — Implement programs that transform input data into specified outputs.
- **MS-DE04: Document source-to-target mappings** — Record how source fields become target fields, including transformation rules.
- **MS-DE08: Design data integration flows** — Specify how data moves between source and destination systems.

## Study and practice sequence

## Assigned tasks and submission evidence


In Data pipeline implementation and integration, demonstrate the following middle tasks:

- MS-DE02: Build a processing application that handles invalid records, repeat runs and routine failures independently.
- MS-DE04: Resolve ambiguous mappings with stakeholders; validate types, defaults and exceptional records independently.
- MS-DE08: Design an integration flow with dependencies, interface contracts and failure handling independently.

Submit evidence:

- MS-DE02: Runnable application, input/output fixtures, test results and execution logs.
- MS-DE04: Mapping document, sample transformations, exception decisions and validation results.
- MS-DE08: Flow diagram, contracts, failure scenarios and design decisions.
