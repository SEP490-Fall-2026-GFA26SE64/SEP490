## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-QA-J-EXEC-02

- Classify defect severity using supplied impact examples and propose a priority with guidance.
- Defect evidence, severity rationale, priority proposal and impact assessment.

### Practice adapted from MOD-QA-M-EXEC-02

- Assess defect impact independently with reproducible evidence; explain severity and repair priority separately.
- Defect evidence, severity rationale, priority proposal and impact assessment.

### Practice adapted from MOD-QA-S-EXEC-02

- Review disputed defect classifications; justify release consequences using exposure, workarounds and evidence limits.
- Defect evidence, severity rationale, priority proposal and impact assessment.
