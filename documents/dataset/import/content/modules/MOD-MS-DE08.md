## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-DE-J-PIPE-01

- Describe a source-to-destination flow from a supplied integration design.
- Flow diagram, contracts, failure scenarios and design decisions.

### Practice adapted from MOD-DE-M-PIPE-01

- Design an integration flow with dependencies, interface contracts and failure handling independently.
- Flow diagram, contracts, failure scenarios and design decisions.

### Practice adapted from MOD-DE-S-PIPE-01

- Compare integration patterns across systems; justify consistency, latency and recovery trade-offs.
- Flow diagram, contracts, failure scenarios and design decisions.
