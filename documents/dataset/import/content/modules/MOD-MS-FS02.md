## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-FS-J-UI-01

- Implement a supplied interface with keyboard navigation and labelled controls; run guided checks.
- Interface implementation, keyboard/focus checks, assistive-technology observations and fixes.

### Practice adapted from MOD-FS-M-UI-01

- Resolve keyboard, focus and assistive-technology interaction defects independently.
- Interface implementation, keyboard/focus checks, assistive-technology observations and fixes.

### Practice adapted from MOD-FS-S-UI-01

- Review accessibility across complex flows; prioritise barriers and verify design and implementation improvements.
- Interface implementation, keyboard/focus checks, assistive-technology observations and fixes.
