# Junior Data quality and operations - Module 2: Guided validation

Module ID: MOD-DE-J-QUAL-02. Content version: 1.2. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Using explicit data quality rules](../topics/DE-QUAL.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-DE09: Profile source datasets** — Summarise missing values, duplicates and distributions before ingestion.
- **MS-DE14: Apply secure data handling** — Apply access restrictions and approved handling controls to datasets.
- **MS-DE15: Test data pipelines** — Write checks for transformation logic and end-to-end data flow.

## Assigned tasks and submission evidence


In Data quality and operations, demonstrate the following junior tasks:

- MS-DE09: Profile a supplied dataset for missing values, duplicates and distributions using a checklist.
- MS-DE14: Apply a supplied access and handling policy; verify an allowed and a denied operation with guidance.
- MS-DE15: Write tests for a supplied transformation and a small end-to-end pipeline with guidance.

Submit evidence:

- MS-DE09: Profiling output, anomaly examples, risk assessment and sampling rationale.
- MS-DE14: Permission configuration, allow/deny tests and data-handling review.
- MS-DE15: Test code, fixtures, coverage rationale and execution results.
