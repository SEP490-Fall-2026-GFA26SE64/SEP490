# Junior Web interface development - Module 1: Guided implementation

Module ID: MOD-FS-J-UI-01. Content version: 1.2. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Connecting interface meaning and behaviour](../topics/FS-UI.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-FS01: design user interface** — Specify user interface structure and interactions for a user task.
- **MS-FS02: Implement accessible user interfaces** — Implement interfaces that support keyboard and assistive technology use.
- **MS-FS09: Implement responsive layouts** — Adapt layout and content to different viewport sizes.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Learning prerequisites

- Before MS-FS09, demonstrate MS-FS01: Identify the intended interface structure before adapting its layout.

Prerequisites taught within this module are studied first. Cross-module prerequisites are scheduled by the pathway engine. These are pending local learning-order decisions, not claims of universal occupational dependency.

## Assigned tasks and submission evidence


In Web interface development, demonstrate the following junior tasks:

- MS-FS01: Specify screens and interactions for a supplied user task using a guided wireframe.
- MS-FS02: Implement a supplied interface with keyboard navigation and labelled controls; run guided checks.
- MS-FS09: Implement a supplied layout at specified viewport sizes and verify overflow with guidance.

Submit evidence:

- MS-FS01: Wireframes, interaction states, requirement mapping and user-flow review.
- MS-FS02: Interface implementation, keyboard/focus checks, assistive-technology observations and fixes.
- MS-FS09: Implementation, viewport evidence, overflow checks and layout rationale.
