## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-FS-J-QUALITY-01

- Review a bounded change using a supplied checklist and give actionable feedback.
- Review comments, linked code changes, decision record and follow-up checks.

### Practice adapted from MOD-FS-M-QUALITY-01

- Review a feature change independently for correctness, tests and maintainability; verify resolved comments.
- Review comments, linked code changes, decision record and follow-up checks.

### Practice adapted from MOD-FS-S-QUALITY-01

- Lead review of a complex change; justify trade-offs and coach reviewers using concrete evidence.
- Review comments, linked code changes, decision record and follow-up checks.
