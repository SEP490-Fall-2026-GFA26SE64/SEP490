- **MS-DE10: Implement data extraction** — Extract source records into a controlled staging area.
- **MS-DE11: Implement transformation rules** — Convert values and enforce business rules during data processing.
- **MS-DE12: Orchestrate retry-safe pipeline tasks** — Order dependent tasks and make retries preserve correct outputs.

## Assigned tasks and submission evidence


In Data pipeline implementation and integration, demonstrate the following senior tasks:

- MS-DE10: Compare extraction approaches under source limits and schema changes; verify recovery without omissions or duplicates.
- MS-DE11: Review conflicting transformation approaches; justify semantic correctness and control downstream change impact.
- MS-DE12: Design orchestration for partial failures and concurrent runs; justify retry boundaries and verify output consistency.

Submit evidence:

- MS-DE10: Extraction code, checkpoints, reconciliation and recovery test logs.
- MS-DE11: Rule specification, transformation code, edge-case fixtures and test results.
- MS-DE12: Dependency graph, orchestration configuration and repeated-run/failure test results.
