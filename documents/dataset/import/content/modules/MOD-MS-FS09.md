## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-FS-J-UI-01

- Implement a supplied layout at specified viewport sizes and verify overflow with guidance.
- Implementation, viewport evidence, overflow checks and layout rationale.

### Practice adapted from MOD-FS-M-UI-01

- Build responsive layouts independently; resolve content, resizing and interaction defects.
- Implementation, viewport evidence, overflow checks and layout rationale.

### Practice adapted from MOD-FS-S-UI-01

- Review layout strategies across complex screens; justify breakpoints and validate representative device scenarios.
- Implementation, viewport evidence, overflow checks and layout rationale.
