# Apply equivalence partitioning — Guided practice

## Learning objective

Practice **Apply equivalence partitioning** at intermediate level. This is pre-published development sample content; it is not a human-reviewed course.

## Scenario and task

Divide the input domain of a discount rule into valid and invalid equivalence classes. Select representative inputs and explain expected results.

## Level-specific practice

Handle two input variations and one failure case independently. Explain the trade-offs and check the result.

## Evidence to keep

Keep the small learning artifact, expected-versus-observed checks and a short explanation of your decisions. Use synthetic inputs and record any assumptions.
