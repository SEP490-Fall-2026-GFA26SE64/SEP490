# Use semantic HTML — Guided practice

## Learning objective

Practice **Use semantic HTML** at intermediate level. This is pre-published development sample content; it is not a human-reviewed course.

## Scenario and task

Create a semantic HTML page for an internal help article and feedback form. Use an appropriate heading hierarchy, landmarks and labelled form controls.

## Level-specific practice

Handle two input variations and one failure case independently. Explain the trade-offs and check the result.

## Evidence to keep

Keep the small learning artifact, expected-versus-observed checks and a short explanation of your decisions. Use synthetic inputs and record any assumptions.

## Completion and assessment

Complete the lesson, then take the configured Skill assessment for MS_FS10_INTERMEDIATE. Reading or marking the module complete does not award official achievement; the assessment and applicable prerequisite rules still apply.
