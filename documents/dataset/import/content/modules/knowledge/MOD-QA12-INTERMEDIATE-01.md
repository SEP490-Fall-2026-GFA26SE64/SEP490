# Prepare test data and environments — Guided practice

## Learning objective

Practice **Prepare test data and environments** at intermediate level. This is pre-published development sample content; it is not a human-reviewed course.

## Scenario and task

Prepare synthetic customer/order records and a disposable environment configuration. Document setup, cleanup, isolation and how another learner can reproduce the same starting state.

## Level-specific practice

Handle two input variations and one failure case independently. Explain the trade-offs and check the result.

## Evidence to keep

Keep the small learning artifact, expected-versus-observed checks and a short explanation of your decisions. Use synthetic inputs and record any assumptions.
