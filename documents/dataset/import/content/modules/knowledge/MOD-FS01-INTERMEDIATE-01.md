# design user interface — Guided practice

## Learning objective

Practice **design user interface** at intermediate level. This is pre-published development sample content; it is not a human-reviewed course.

## Scenario and task

Design a registration form for a small internal application. Show field labels, validation feedback, empty/loading states and keyboard navigation.

## Level-specific practice

Handle two input variations and one failure case independently. Explain the trade-offs and check the result.

## Evidence to keep

Keep the small learning artifact, expected-versus-observed checks and a short explanation of your decisions. Use synthetic inputs and record any assumptions.
