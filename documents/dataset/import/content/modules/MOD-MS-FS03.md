## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-FS-J-SERVICE-01

- Define a small component interface from a supplied contract template with guidance.
- Interface specification, request/response examples, contract tests and design rationale.

### Practice adapted from MOD-FS-M-SERVICE-01

- Design application contracts and error behaviour across components independently; test consumers.
- Interface specification, request/response examples, contract tests and design rationale.

### Practice adapted from MOD-FS-S-SERVICE-01

- Compare interface alternatives under compatibility and failure constraints; justify evolution and migration decisions.
- Interface specification, request/response examples, contract tests and design rationale.
