## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-FS-J-UI-01

- Specify screens and interactions for a supplied user task using a guided wireframe.
- Wireframes, interaction states, requirement mapping and user-flow review.

### Practice adapted from MOD-FS-M-UI-01

- Design an end-to-end user flow independently; validate navigation and error states against requirements.
- Wireframes, interaction states, requirement mapping and user-flow review.

### Practice adapted from MOD-FS-S-UI-01

- Review alternative interface designs across complex flows; justify recommendations using user-task evidence.
- Wireframes, interaction states, requirement mapping and user-flow review.
