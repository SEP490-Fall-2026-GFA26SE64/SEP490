## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-DE-J-MODEL-01

- Create an entity model from supplied requirements; verify keys and relationships against sample records.
- Model diagram, schema, constraint checks and design rationale.

### Practice adapted from MOD-DE-M-MODEL-01

- Independently design a model for multiple consumers; validate constraints and explain normalisation choices.
- Model diagram, schema, constraint checks and design rationale.

### Practice adapted from MOD-DE-S-MODEL-01

- Compare cross-domain model alternatives; justify performance and change-impact trade-offs and review another design.
- Model diagram, schema, constraint checks and design rationale.
