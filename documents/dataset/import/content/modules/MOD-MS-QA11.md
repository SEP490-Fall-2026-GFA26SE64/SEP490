## Focused practice

Choose the practice appropriate to the selected Level. These are retained local proposals, not official framework scoring standards.

### Practice adapted from MOD-QA-J-DESIGN-02

- Rank supplied tests using a given likelihood-and-impact checklist with guidance.
- Risk register, prioritised tests, evidence sources and residual-risk statement.

### Practice adapted from MOD-QA-M-DESIGN-02

- Prioritise tests independently using product impact, failure likelihood and available evidence.
- Risk register, prioritised tests, evidence sources and residual-risk statement.

### Practice adapted from MOD-QA-S-DESIGN-02

- Review risk priorities under release constraints; justify changes and communicate untested residual risks.
- Risk register, prioritised tests, evidence sources and residual-risk statement.
