# Junior Data quality and operations - Module 1: Guided implementation

Module ID: MOD-DE-J-QUAL-01. Content version: 1.0. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Using explicit data quality rules](../topics/DE-QUAL.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-DE05: Verify data quality** — Check records against explicit completeness, accuracy and consistency rules.
- **MS-DE06: Maintain metadata documentation** — Record dataset meaning, ownership and structural metadata.
- **MS-DE07: Monitor pipeline operations** — Observe pipeline runs and investigate operational failures.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Assigned tasks and submission evidence


In Data quality and operations, demonstrate the following junior tasks:

- MS-DE05: Run supplied completeness, accuracy and consistency checks; record failures with guidance.
- MS-DE06: Fill a supplied data dictionary with field meanings, owners and structural metadata.
- MS-DE07: Read pipeline logs and alerts; reproduce a known failure and document escalation with guidance.

Submit evidence:

- MS-DE05: Quality rules, failing records, investigation notes and rerun results.
- MS-DE06: Data dictionary, ownership records, change history and review findings.
- MS-DE07: Run logs, alert examples, incident timeline and recovery verification.
