## Skill focus

- **MS-AI09: Select data split strategies** — Choose random, stratified, grouped or temporal splits to match the data.
- **MS-AI12: Assess class imbalance** — Inspect class frequencies and choose evaluation measures that reveal minority-class errors.

## Study and practice sequence

2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Assigned tasks and submission evidence


In ML data preparation, demonstrate the following senior tasks:

- MS-AI09: Review split alternatives for a complex deployment setting; expose contamination risks and justify representativeness.
- MS-AI12: Review imbalance evaluation under changing class frequencies and error costs; justify decision thresholds.

Submit evidence:

- MS-AI09: Split code, partition manifests, overlap tests and strategy rationale.
- MS-AI12: Class counts, per-class metrics, error examples and threshold rationale.
