Module ID: MOD-QA-M-AUTO-01. Content version: 1.0. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Making automated checks reliable](../topics/QA-AUTO.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-QA06: develop automated software tests** — Implement repeatable automated tests with meaningful assertions.
- **MS-QA07: execute integration testing** — Test interactions and data exchange between components.
- **MS-FS07: perform software unit testing** — Verify individual units of software with repeatable automated checks.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.

## Assigned tasks and submission evidence


In Test automation and integration, demonstrate the following middle tasks:

- MS-QA06: Implement repeatable automated tests independently with meaningful assertions and controlled test data.
- MS-QA07: Design and execute integration tests independently for contracts, data exchange and failures.
- MS-FS07: Design isolated unit tests for normal, boundary and failure behaviour independently.

Submit evidence:

- MS-QA06: Automation code, fixtures, assertion rationale and repeat-run results.
- MS-QA07: Interaction map, integration cases, execution results and failure evidence.
- MS-FS07: Unit tests, fixtures, execution results and assertion rationale.
