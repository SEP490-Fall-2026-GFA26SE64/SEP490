# Middle Software quality and delivery - Module 1: Independent implementation

Module ID: MOD-FS-M-QUALITY-01. Content version: 1.0. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Building a repeatable change check](../topics/FS-QUALITY.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-FS06: debug software** — Locate and correct causes of software defects.
- **MS-FS07: perform software unit testing** — Verify individual units of software with repeatable automated checks.
- **MS-FS08: conduct ICT code review** — Review source changes and give actionable technical feedback.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Assigned tasks and submission evidence


In Software quality and delivery, demonstrate the following middle tasks:

- MS-FS06: Diagnose a defect across components independently; explain its cause and verify the fix.
- MS-FS07: Design isolated unit tests for normal, boundary and failure behaviour independently.
- MS-FS08: Review a feature change independently for correctness, tests and maintainability; verify resolved comments.

Submit evidence:

- MS-FS06: Reproduction steps, diagnostic evidence, patch and regression results.
- MS-FS07: Unit tests, fixtures, execution results and assertion rationale.
- MS-FS08: Review comments, linked code changes, decision record and follow-up checks.
