# Junior ML data preparation - Module 1: Guided implementation

Module ID: MOD-AI-J-DATA-01. Content version: 1.0. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Protecting the evaluation boundary](../topics/AI-DATA.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-AI01: create data sets** — Assemble a dataset suitable for a stated modelling task.
- **MS-AI02: Prepare leakage-safe training data** — Fit preprocessing on training data without leaking evaluation information.
- **MS-AI03: Construct and select model features** — Build or select input features relevant to the prediction task.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Learning prerequisites

- Before MS-AI02, demonstrate MS-AI01: Identify modelling records and targets before defining preprocessing boundaries.
- Before MS-AI03, demonstrate MS-AI02: Preserve training/evaluation separation while constructing learned features.

Prerequisites taught within this module are studied first. Cross-module prerequisites are scheduled by the pathway engine. These are pending local learning-order decisions, not claims of universal occupational dependency.

## Assigned tasks and submission evidence


In ML data preparation, demonstrate the following junior tasks:

- MS-AI01: Assemble a dataset from supplied sources and document target labels with guidance.
- MS-AI02: Apply a provided train/test split and fit preprocessing on training data only with guidance.
- MS-AI03: Construct supplied features and check their values against examples with guidance.

Submit evidence:

- MS-AI01: Dataset manifest, label checks, inclusion rules and dataset summary.
- MS-AI02: Preprocessing pipeline, fit boundaries, split records and leakage tests.
- MS-AI03: Feature definitions, baseline comparison, validation results and feature checks.
