# Junior Application services and data - Module 1: Guided implementation

Module ID: MOD-FS-J-SERVICE-01. Content version: 1.0. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Making service boundaries explicit](../topics/FS-SERVICE.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-FS03: design application interfaces** — Define interfaces through which application components exchange information.
- **MS-FS04: use query languages** — Retrieve and manipulate data using a query language.
- **MS-FS05: integrate system components** — Connect components and verify their combined behaviour.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Learning prerequisites

- Before MS-FS05, demonstrate MS-FS03: Understand the component contract before connecting components.

Prerequisites taught within this module are studied first. Cross-module prerequisites are scheduled by the pathway engine. These are pending local learning-order decisions, not claims of universal occupational dependency.

## Assigned tasks and submission evidence


In Application services and data, demonstrate the following junior tasks:

- MS-FS03: Define a small component interface from a supplied contract template with guidance.
- MS-FS04: Write queries for supplied retrieval and update tasks; verify results against sample records.
- MS-FS05: Connect supplied components and verify a bounded end-to-end scenario with guidance.

Submit evidence:

- MS-FS03: Interface specification, request/response examples, contract tests and design rationale.
- MS-FS04: Query scripts, expected results, edge-case data and execution measurements.
- MS-FS05: Integration diagram, runnable feature, contract checks and failure tests.
