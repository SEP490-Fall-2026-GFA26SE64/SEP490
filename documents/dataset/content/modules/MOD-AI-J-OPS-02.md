## Assigned tasks and submission evidence


In Model deployment and operations, demonstrate the following junior tasks:

- MS-AI14: Record seeds, parameters and environment details; repeat a supplied experiment with guidance.
- MS-AI15: Run supplied contract checks for prediction inputs and outputs in a guided integration trial.
- MS-AI16: Document a maintenance runbook from a supplied deterioration scenario with guidance.

Submit evidence:

- MS-AI14: Run manifest, version records, repeated-run outputs and difference analysis.
- MS-AI15: Contracts, integration tests, request/response fixtures and failure results.
- MS-AI16: Maintenance runbook, trigger rationale, revalidation results and rehearsal record.
