# Senior Test execution and defect evidence - Module 2: Complex validation and improvement

Module ID: MOD-QA-S-EXEC-02. Content version: 1.0. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Keeping test evidence reproducible](../topics/QA-EXEC.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-QA12: Prepare test data and environments** — Set up controlled inputs and system conditions required for repeatable tests.
- **MS-QA13: Classify defect impact** — Describe defect severity and propose a repair priority with evidence.
- **MS-QA14: Run regression tests** — Check that changes have not broken previously working behaviour.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Learning prerequisites

- Before MS-QA14, demonstrate MS-QA03: Execute and record a test reliably before interpreting repeat runs after a change.

Prerequisites taught within this module are studied first. Cross-module prerequisites are scheduled by the pathway engine. These are pending local learning-order decisions, not claims of universal occupational dependency.

## Assigned tasks and submission evidence


In Test execution and defect evidence, demonstrate the following senior tasks:

- MS-QA12: Review environment and data strategies across suites; diagnose instability and justify maintenance controls.
- MS-QA13: Review disputed defect classifications; justify release consequences using exposure, workarounds and evidence limits.
- MS-QA14: Review regression strategy across releases; justify coverage versus execution cost and verify improvements.

Submit evidence:

- MS-QA12: Data fixtures, environment manifest, readiness checks and repeatability evidence.
- MS-QA13: Defect evidence, severity rationale, priority proposal and impact assessment.
- MS-QA14: Change-impact map, selected tests, run results and failure investigation.
