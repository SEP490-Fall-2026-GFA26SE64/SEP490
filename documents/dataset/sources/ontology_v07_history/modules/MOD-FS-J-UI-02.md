# Junior Web interface development - Module 2: Guided validation

Module ID: MOD-FS-J-UI-02. Content version: 1.1. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Connecting interface meaning and behaviour](../topics/FS-UI.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-FS10: Use semantic HTML** — Choose elements whose meaning matches the content and interaction.
- **MS-FS11: Handle asynchronous web requests** — Handle successful responses, HTTP failures and request cancellation in the interface.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Assigned tasks and submission evidence


In Web interface development, demonstrate the following junior tasks:

- MS-FS10: Choose HTML elements for supplied content and interactions; check structure with guidance.
- MS-FS11: Handle success and failure responses in a supplied interface with guidance.

Submit evidence:

- MS-FS10: Markup, structure checks, interaction examples and review notes.
- MS-FS11: Request-handling code, state transitions and error/cancellation/race tests.
