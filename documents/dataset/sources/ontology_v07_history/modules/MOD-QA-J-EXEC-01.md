# Junior Test execution and defect evidence - Module 1: Guided implementation

Module ID: MOD-QA-J-EXEC-01. Content version: 1.1. Review: NEEDS_EXPERT_REVIEW.

## Learn

Read [the local lesson: Keeping test evidence reproducible](../topics/QA-EXEC.md). It includes a conceptual explanation, worked example and a self-check with an answer. Then use the linked official resources for additional detail.

## Skill focus

- **MS-QA03: execute software tests** — Run specified tests and record observed results.
- **MS-QA04: report test findings** — Communicate test results and defects with supporting evidence.
- **MS-QA05: replicate customer software issues** — Reproduce a reported issue under identified conditions.

## Study and practice sequence

1. Read the linked local explanation and work through its example.
2. Answer the self-check before looking at the answer.
3. Inspect the official learning resources below for the techniques used in this module.
4. Complete the assigned tasks below and record checks and evidence.

## Assigned tasks and submission evidence


In Test execution and defect evidence, demonstrate the following junior tasks:

- MS-QA03: Execute supplied tests and record expected and observed results with guidance.
- MS-QA04: Write a defect report with steps, expected and actual results using a supplied template.
- MS-QA05: Reproduce a reported issue using supplied conditions and record the result with guidance.

Submit evidence:

- MS-QA03: Execution log, environment details, expected/actual results and failure evidence.
- MS-QA04: Defect reports, supporting evidence, test summary and decision notes.
- MS-QA05: Reproduction steps, environment comparison, logs and controlled reruns.
