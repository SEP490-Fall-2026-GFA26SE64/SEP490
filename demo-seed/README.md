# Bộ seed demo riêng

Bộ dữ liệu thực tế nằm trong [council-v1](council-v1/README.md). Đây là fixture và công cụ nạp riêng, không được nối vào seed/Compose mặc định. Dùng DB, volume, cổng và tài khoản học riêng để tập trước khi quyết định đưa vào bộ chính.

Đã kiểm tra offline bằng chính bộ chấm Java. Chưa nạp DB/chạy xuyên suốt vì Docker Linux engine hiện không kết nối được. Xem hướng dẫn và giới hạn tại README của bộ dữ liệu.
